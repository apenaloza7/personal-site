# personal-site

🚀 Welcome to the codebase for my personal slice of the internet! 🚀

This is where the magic happens for my corner of the web. Dive in, explore, or just admire the digital craftsmanship. 😉

## ✨ Features

*   Interactive terminal simulation 🖥️
*   Dark mode toggle 🌙/☀️
*   CSS animations (typing effect, fade-ins) ✨
*   Built with Tailwind CSS for rapid UI development
*   Responsive design for mobile and desktop
*   Analytics with Inspectlet

## 🛠️ Tech Stack

*   **Frontend:** HTML, Tailwind CSS, Vanilla JavaScript
*   **Icons:** Font Awesome
*   **Analytics:** Inspectlet
*   **Deployment:** GitHub Pages (FREE!)

## 🏃‍♂️ Running Locally

Want to take it for a spin?

1.  **Clone the repo:**
    ```bash
    git clone https://github.com/apenaloza7/personal-site.git
    cd personal-site
    ```
2.  **Open `index.html`:**
    Simply open the `index.html` file directly in your web browser.
    No installation or build step required!
